## Опис архітектури
Програма базується на модульній архітектурі з попередньої роботи, але містить новий підхід до обробки даних:
* `Main Thread (UI)`: Основний потік читає кадри з камери, оновлює інтерфейс, відправляє кадри у фоновий потік та забирає останні відомі координати для малювання рамки.
* `Worker Thread` (у класі `FaceDetector`): Фоновий потік очікує нові кадри, запускає інференс нейромережі (ResNet-10 SSD) через `cv::dnn`, та безпечно (через `std::mutex`) оновлює спільний масив з координатами знайдених облич.

Завдяки розділенню потоків, інтерфейс та відео не зависають (FPS залишається високим), навіть якщо нейромережа довго обробляє кадр.

## Інструкція зі збірки та запуску
1. Встановлення залежностей та завантаження моделі: `./preinstall.sh`
2. Компіляція проєкту: `./build.sh`
3. Запуск програми: `./run.sh`
