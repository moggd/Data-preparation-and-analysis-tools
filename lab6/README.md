# Лабораторна робота №6: C++ OpenCV

**Виконав:** Микуляк Марко, група ФБ-46

## Опис програми
Програма реалізує модульну архітектуру на C++ з використанням OpenCV. Вона захоплює відео з веб-камери, дозволяє змінювати режими обробки клавішами (1-5), малювати прямокутники мишкою, регулювати яскравість слайдером та виводить FPS на екран.

## Вимоги до ОС та заліза
* **ОС:** macOS / Linux (Ubuntu)
* **Залізо:** Наявність веб-камери.
* **Залежності:** `cmake`, `gcc/g++`, `libopencv-dev` (Linux) або `opencv` (macOS).

## Інструкція із запуску (з першої спроби)
1. Встановлення залежностей: `./preinstall.sh`
2. Компіляція проєкту: `./build.sh`
3. Запуск програми: `./run.sh`
